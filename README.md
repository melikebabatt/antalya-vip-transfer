# Caretta VIP Antalya Airport Transfer

Static website for Caretta VIP Antalya Airport Transfer.

## Included
- 7/24 VIP transfer presentation
- From / To transfer request flow (airport selector and payment choice removed)
- One-way and round-trip requests
- Open address + map location selection
- Vehicle options with photos: VIP Private, Crafter, Sprinter, Maybach Lüks
- Vehicle photos also shown inside the quote/transfer options modal
- WhatsApp quote request with the supplied number
- Instagram and Facebook links
- Turkish, English, Russian, German, Arabic and Persian UI
- Customer reviews section (real reviews can be added later)
- Membership UI (browser-local demo)
- Responsive mobile/desktop design

## Important
The membership screen is currently a front-end/local-browser prototype. For real accounts that work across devices, connect Cloudflare Workers + D1 (or another database/auth provider). No real passwords should be stored in localStorage in a production site.
