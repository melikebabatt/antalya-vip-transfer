# Antalya VIP Transfer

Responsive airport transfer landing/booking interface for Antalya Airport (AYT) and Gazipaşa-Alanya Airport (GZP).

## Included
- One-way / round-trip reservation flow
- Airport and destination selection
- Antalya district/area list
- Passenger, date, time and flight number fields
- VIP Sedan / Vito / Minibus vehicle selection
- Cash / credit-card payment preference UI
- WhatsApp reservation handoff
- Turkish / English / Russian / German UI
- Campaigns, fleet and contact sections
- Mobile responsive design

## Before going live
1. Set the WhatsApp number in `js/app.js`.
2. Replace the generic business name/logo text.
3. Add real vehicle photos and campaign text if desired.
4. Add route prices if the business wants instant price quotes.
5. For real online card payments, connect an approved payment provider and complete the required business/KYC setup.
6. Add/review KVKK, privacy, cancellation and service terms before taking paid bookings.

## Deploy
This is a static site and can be deployed from GitHub to a static host. Cloudflare Pages supports Git integration and automatic deployments from GitHub.
